# 记忆总结助手 Memory Summarizer

一个 SillyTavern（酒馆）第三方扩展，用于自动/手动把最近若干条对话总结成摘要，
每次总结生成一个独立条目、按时间顺序追加保存，可编辑/删除/复制，支持一键复制、
注入到上下文（相当于引用到"预设"）、写入世界书条目，并支持导入/导出。

## 功能

### 长期记忆（剧情摘要）
- **可设置总结条数**：设定每 N 条新对话自动触发一次总结。
- **自定义总结提示词**：模板中用 `{{content}}` 代表要总结的对话原文。
- **风格参考（统一多次总结的文风）**：开启后，每次生成新摘要时会把最近几条旧摘要一起发给 AI，
  并在提示词里明确写明"这些仅供参考、不需要重新总结"，用来让所有摘要保持统一的写作风格、语气和剧情脉络。
  旧摘要本身绝不会被修改或重新生成——新摘要永远只是追加在数组末尾，不会碰旧的记录。
  参考条数（默认 3 条）和是否开启都可以在面板里调整。
- **手动总结提醒**：如果关闭了"达到条数自动总结"（即手动总结模式），插件会在待总结消息达到设定条数时
  弹出第一次提醒，超出设定 5 条时弹出第二次提醒，之后不再打扰，直到完成一次总结后重置。
- **进度与统计**：面板顶部实时显示可总结消息数（排除系统消息）、已有摘要条数、核心记忆条数、
  摘要总字数、上次更新时间，以及一条到下次自动触发的进度条。
- **总结内容持久化**：每条摘要保存在当前聊天的 metadata 里（随存档走，不会因为切换角色卡而串到别的对话），
  可直接在文本框内编辑；每条摘要右上角会显示它**真实的总结完成时间**。
- **可编辑 / 删除，且不会"退回未总结"**：删除某条摘要文本，只是删掉这段摘要，
  对应的那些消息不会因此重新变成"待总结"状态，不会被重复计入下一次总结、不会重复消耗 Token。
- **自动/手动标签**：每条摘要会标注是自动触发还是手动点击生成的，方便回顾。
- **全流程 toast 提示**：自动总结触发、生成成功、生成失败都会弹出提示；失败时会带上具体原因（比如接口报错信息、返回为空等），不用去翻控制台也能大致判断问题出在哪。
- **长列表性能优化**：长期记忆列表默认只显示最近 20 条（可在设置中调整），超出时显示"展开全部"按钮，
  避免几百条摘要时页面卡顿。

### 核心记忆（关键事实提取）
- **从长期记忆中提取**：在长期记忆列表中勾选多条摘要，点击"提取核心"按钮，AI 会从中提取生日、约定、
  作息、兴趣、重要事件和物品等永久性事实，生成一条核心记忆条目。
- **自定义核心记忆提示词**：模板中用 `{{content}}` 代表选中的摘要内容。
- **提取后可选保留或删除原始长期记忆**：选择"保留"会把已提取核心的长期记忆合并为一条，
  放在最旧的记忆后面；选择"删除"则直接移除（总结进度不受影响）。
- **优先级高于长期记忆**：自动注入上下文时，核心记忆会排在长期记忆前面，
  并标注为"绝对不可违反、不可遗忘"，确保 AI 始终遵守。
- **独立管理**：核心记忆有独立的展示区域，支持编辑、删除、复制，
  同样显示总条目、总字数、上次更新时间等统计信息。

### 通用功能
- **一键复制**：单条复制 / 复制全部。
- **自动注入上下文**：勾选后，最近 N 条核心记忆和最近 N 条长期记忆会通过 `setExtensionPrompt`
  自动注入到发给 AI 的提示词里（可设置位置 / 深度 / 角色）。
  生成新摘要期间会临时关闭这个注入，避免总结这次新内容时把刚注入的旧摘要又重复喂给 AI 一次，总结完成后自动恢复。
- **写入世界书（带预览确认）**：选择一个已有世界书和插入位置，给某条摘要填写关键词（留空则设为常驻条目），
  点击后会先弹出预览框，显示即将写入的世界书、位置、关键词和完整内容，确认无误后才会真正写入。
  插入位置从当前酒馆版本实际支持的位置列表里动态读取，版本不支持时会自动禁用该选项并提示，不会盲目写入。
  完全不想用世界书的话，用"复制全部总结"手动粘贴即可，不点"写入世界书"就不会有任何自动写入行为。
- **导入 / 导出**：可以把当前聊天的全部摘要（含长期记忆和核心记忆）、总结进度和插件设置打包导出成一个
  JSON 文件，方便备份或换设备；导入时可以分别勾选"只导入摘要""只导入核心记忆""只导入设置"，
  摘要会追加在当前聊天已有摘要之后，不会覆盖/删除已有数据。

## 安装方法

1. 打开 SillyTavern 所在服务器/手机的文件目录，找到：
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```
2. 把整个 `tavern-memory-summarizer` 文件夹复制进去（保持文件夹名不变，或改成你喜欢的名字都行）。
3. 重启酒馆前端（刷新网页也可以，多数情况下不需要重启后端）。
4. 打开右上角「扩展」面板（Extensions），下拉找到 **记忆总结助手**，展开即可看到设置面板（展开状态会被记住，下次打开自动保持）。

## 使用建议

- **总结条数**：如果角色对话比较啰嗦，建议设置 15~30 条比较合适；条数太小会导致频繁调用 API 增加消耗。
- **提示词模板**：默认模板已经比较通用，如果你想要保留更多细节/更短/更第一人称，可以直接改文本框里的内容，改完自动保存。
- **风格参考条数**：条数越大，AI 越能贴合你之前的摘要风格，但也会增加每次总结的 token 消耗；一般 2~5 条就够用了，觉得风格已经稳定后也可以关掉这个选项省 token。
- **自动注入**：如果你已经在预设里手动引用了摘要，就不要同时打开自动注入，避免摘要被重复喂给模型两次。
- **积压很多消息时**：如果是刚给一个很长的老聊天装上本插件，自动总结会按"设定条数"一块一块处理，不会一次性把几百条消息塞给 AI；如果想马上补齐全部积压，点一次"立即总结一次"即可（手动总结会一次性处理全部积压内容）。
- **清空摘要 ≠ 重置进度**：这是两个独立按钮。只是不想看到某些摘要文字了，用"清空摘要文本"就够了，
  总结进度不受影响；只有真的想让插件从头重新总结整个聊天时，才需要额外点"重置总结进度"，
  注意这在开着自动总结时可能会连续触发较多新的总结请求、消耗较多 Token。
- **核心记忆的使用时机**：当长期记忆积累了较多条目（比如 10 条以上）后，建议勾选其中包含重要事实的几条，
  提取一次核心记忆。核心记忆适合存放角色生日、重要约定、确定下来的关系、作息习惯等不会随剧情变化的永久信息；
  剧情经过类的内容留在长期记忆里就好。
- **手动总结模式**：如果你关闭了"达到条数自动总结"，插件会在待总结消息达到设定条数时弹出提醒，
  超出 5 条时再提醒一次，之后不会再打扰，让你按自己节奏来。
- **换设备 / 备份**：用面板底部的"导出记忆数据"打一个 JSON 备份，换设备后用"导入记忆数据"选择只导入设置、
  或者把摘要也一起导入（会追加，不会覆盖当前聊天已有的摘要）。

## 关于兼容性的说明

SillyTavern 本体更新较快，扩展依赖的几个内部接口（`generateQuietPrompt`、
`setExtensionPrompt`、`world-info.js` 里的 `loadWorldInfo` / `saveWorldInfo` /
`createWorldInfoEntry` / `world_info_position` 等）在不同版本里参数或导出方式可能略有差异。

本扩展已经按目前主流稳定版的接口约定编写，并且对"世界书插入位置"这类枚举值做了运行时探测
（直接读取当前酒馆版本实际导出的位置列表，而不是写死一份可能过时的数值），如果你更新酒馆后发现：

- **"立即总结"没反应或报错** → 面板上会直接弹出失败原因的提示；如果提示不够清楚，打开浏览器控制台（F12，或手机浏览器的"检查"/远程调试）看 `[记忆总结助手]` 开头的报错信息即可定位，通常是 `generateQuietPrompt` 签名变化。
- **"写入世界书"按钮报错** → 说明 `world-info.js` 的导出名称在你的版本里变了，这种情况下**复制按钮永远可用**，可以手动粘贴到世界书里，不影响核心的"总结存储"功能。
- **"插入位置"下拉框被禁用/只有一个提示选项** → 说明当前酒馆版本没有导出 `world_info_position`，写入世界书时会使用该世界书自己的默认插入位置，不影响写入本身。
- **自动注入没生效** → 检查是否同时开启了"自动总结"，以及 `injectPosition` 是否与你的模型/预设兼容（文本补全类模型 IN_CHAT 更常用，聊天补全类模型 IN_PROMPT 更常用）。

如果报错，把浏览器控制台里 `[记忆总结助手]` 开头的日志发给我，我可以帮你针对你那个版本再调整对应的接口调用。

## 已知局限

- 总结进度是按"消息下标"追踪的，不是按每条消息的唯一 ID 追踪。如果你删除的是**较早、已经被总结过**的消息，
  摘要内容和实际消息之间的对应关系会出现偏差（进度指针本身不会崩溃或卡死，只是"消息 12-31"这类范围标注可能对不上了）。
  这是当前实现方式的固有局限，如果后续需要做成精确到每条消息 ID 的追踪，请告诉我，可以再单独升级。
